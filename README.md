# YouTube Archiver releases

Installers for YouTube Archiver, a Windows app that archives YouTube videos for Jellyfin.

This repository only holds release downloads. Archiver checks it once a day and offers new versions in Settings → Updates; the installer is verified against the SHA-256 that GitHub publishes for it before it runs.

- **Setup.exe** installs or updates Archiver for your Windows account.
- **Portable.zip** runs without installing.

See [Releases](https://github.com/some-guy-john/yt-archiver-releases/releases).
